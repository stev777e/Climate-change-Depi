# Climate Change Analysis & Visualization

A Team 4 project exploring climate data, greenhouse-gas emissions, and related economic and population indicators through data analysis and visualization.

## Project goals

- Explore historical climate and emissions trends.
- Prepare and combine public datasets for analysis.
- Present findings with charts and an interactive dashboard.
- Investigate future climate impacts and communicate climate-action insights.

### Main files

- **`climate_change_analysis.ipynb`** — notebook for the main climate analysis.
- **`climate_analysis_dashboard.html`** — exported interactive dashboard; open it in a browser.
- **`ch4_mm_gl.csv`** and **`track_a_monthly_global_climate_1979_2026.csv`** — climate data files.
- **`Mahmoud Hafez (3)/`** — supporting emissions, GDP, and population datasets and Python analysis/visualization scripts.
- **`climate_change_analysis_project.zip`** — archived project files. Check its contents before treating it as the canonical source; some files may overlap with the repository.

## Getting started

1. Clone or download this repository.
2. Open `climate_change_analysis.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab to explore the analysis.
3. Open `climate_analysis_dashboard.html` in a modern web browser to view the dashboard.
4. Review the Python scripts in `Mahmoud Hafez (3)/Final Project/` for the supporting analyses.

The repository currently does not include a dependency lockfile or a documented, tested setup command. Install the packages required by the notebook or scripts in your Python environment before running them.

## Data and reproducibility

The repository includes CSV datasets and an archived project ZIP. Please document the source, license, date downloaded, units, and any transformations for each dataset before reusing or publishing results. Keep raw source data distinct from cleaned or derived data when extending the project.
